## KAY LIVE SPORT TV v0.1.23 Preview

Compatibility build accompanying the Windows/Phone-Tablet Myanmar TV and lazy-loading release.

- Retains TV page-entry lazy loading, stable focus, four-column Matches/Live, Myanmar TV and Settings-only startup persistence.
- Shares channel parsing, stream resolution and channel UI with Windows and Phone/Tablet.
- Included in android-v0.1.23 so existing TV update discovery continues to find matching ARM32/ARM64 APKs.

Install the matching TV architecture over the existing app without uninstalling. The application ID and signing certificate are unchanged.

Validation: TV lazy-loading requests/cache/manual refresh, remote navigation, Myanmar TV controls, fullscreen/Back and WebView 81; native APK builds and version/signature/alignment checks. Physical TV behavior has not been verified for this compatibility build.
