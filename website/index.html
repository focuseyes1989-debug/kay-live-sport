A LITTLE HELP

Before kickoff.

မေးလေ့ရှိတဲ့ မေးခွန်းအချို့။

Phone နဲ့ Tablet version ဘာကွာလဲ?

Phone က Matches / Live စာမျက်နှာတစ်ခုတည်းနဲ့ fullscreen ကို ဦးစားပေးထားပါတယ်။ Tablet က မူလ layout နဲ့ Scores၊ Highlights၊ Myanmar TV page တွေ ပါဝင်ပါတယ်။

Settings မပျက်ဘဲ update လုပ်လို့ရလား?

လက်ရှိ app ကို မဖြုတ်ဘဲ ကိုက်ညီတဲ့ edition APK ပေါ်မှာ Update လုပ်ပါ။ လက်ရှိ download တွေက မူလ signing certificate ကို ဆက်သုံးထားပါတယ်။ Reset settings နှိပ်တာ ဒါမှမဟုတ် uninstall လုပ်တာက settings တွေ ဖျက်နိုင်ပါတယ်။

Redmi မှာ ICP / installation warning ဘာကြောင့်ပြတာလဲ?

Redmi installer က app registration မတွေ့တာ ဒါမှမဟုတ် Play Store ပြင်ပက download ဖြစ်တာကြောင့် သတိပေးနိုင်ပါတယ်။ Website က download လုပ်ခြင်းက အဲဒီ warning ကို မဖယ်ရှားပါဘူး။ Warning စာသားကို စစ်ဆေးပြီး မသေချာရင် GitHub မှာ အသေးစိတ်တင်ပြပါ။

ပွဲအားလုံးကို အမြဲကြည့်လို့ရမလား?

Video ရရှိမှုက provider နဲ့ network အခြေအနေအပေါ် မူတည်ပါတယ်။ Score နဲ့ video က သီးခြား source တွေကို သုံးထားလို့ အချိန်ကွာနိုင်ပါတယ်။
