## KAY LIVE SPORT Windows v0.1.15 / Android v0.1.26

League filters now show major competitions first: Champions League, Europa League, English Premier League, La Liga, Serie A, Bundesliga, Ligue 1 and Conference League. Other leagues follow alphabetically. All leagues remains first, and saved league selections are preserved.

Applies to the existing All matches, Live now and Results league filters shared by Windows, Phone/Tablet and TV. TV pages retain their current filter visibility. Score providers remain unchanged.

Downloads: Windows x64 EXE; Phone/Tablet ARM32 and ARM64 APKs; TV ARM32 and ARM64 APKs. Android packages retain the existing application ID and signing certificate and remain preview/debug builds. Install the matching edition over the existing app to preserve settings. Companion Android release: android-v0.1.26.

Validation: Rust and shared UI regression tests, native builds, APK version/signature/alignment and uploaded SHA-256 verification. Physical-device testing is not included in this release.
